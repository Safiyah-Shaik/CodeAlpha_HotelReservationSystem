# CodeAlpha_HotelReservationSystem

A Java-based Hotel Reservation System developed for the CodeAlpha Java Programming Internship.

## Project Overview

The Hotel Reservation System is a web-based application that allows users to view hotel rooms, make bookings, calculate booking prices, make demo payments, and cancel bookings.

## Features

- View available hotel rooms
- Book hotel rooms
- Calculate the total booking price
- View booking details
- Demo payment functionality
- Display payment status
- Cancel bookings
- Simple and user-friendly interface

## Technologies Used

- Java
- Spring Boot
- Maven
- HTML
- CSS
- JavaScript
- REST API

## Project Structure

- `src/main/java` — Java source code and backend controllers
- `src/main/resources/static` — Frontend website
- `src/test/java` — Application test files
- `pom.xml` — Maven dependencies and configuration

## How to Run the Project

1. Clone or download this repository.
2. Open the project in an IDE or GitHub Codespaces.
3. Make sure Java and Maven are available.
4. Open the terminal in the project directory.
5. Run the following command:

   ```bash
   mvn spring-boot:run
   ```

6. Open the website at:

   `http://localhost:8080`

## Payment Note

The Pay Now feature is for demonstration purposes only. It does not process real payments.
